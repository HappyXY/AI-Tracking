## Agent

- *(2026-10-05)* [WikiSkill：让 Agent 变强的不是技能文件，而是那本“失败笔记本”](https://alphasignal.ai/news/self-improving-ai-skills-learn-in-the-notebook-not-the-file) — Google Research 与 Virginia Tech 提出的 WikiSkill 把工作区分为 raw/ 轨迹、wiki/ 私有知识库、skills/ 指令文件三层，由 actor、maintainer、proposer 与严格验证门四个角色循环，proposer 只读取 wiki 索引与 skill-impact.md 账本，每轮只提一条技能改动。关键结论：只有当 proposer 能读到持久化的 wiki 笔记本时，准确率才从 48.7 升到 63.7（LiveMath 51.3→72.6，SpreadSheet 49.9→76.6）；若允许 actor 偷看同一本笔记，平均分反而回落到 60.9，因为被笔记“解出”的轨迹不再暴露技能缺陷。作者据此主张：技能文件只是最终产物，真正值钱的是被永久留存的失败与回滚记录。
- *(2026-10-05)* [Self-Harness：让 Agent 自己改进自己的运行外壳](https://arxiv.org/abs/2606.09498) — 论文指出 Agent 表现由基座模型与 harness 共同决定，而 harness 目前仍靠人工为每个模型定制，无法跟上模型快速迭代。Self-Harness 把改进流程做成三阶段闭环：弱点挖掘（从执行轨迹中找出模型特有失败模式）、harness 提案（生成与失败对应且尽量最小的改动）、提案验证（只有通过回归测试才被接受）。在 Terminal-Bench-2.0、SWE-bench Verified、AppWorld 三个基准与 MiniMax M2.5、Qwen3.5-35B-A3B、GLM-5 三个模型共九种组合上，最终 harness 全部同时提升 held-in 与 held-out 通过率，相对增益最高达 132%。
- *(2026-10-05)* [HarnessX：可组合、可自适应、可进化的 Agent Harness 铸造厂](https://arxiv.org/abs/2606.14249) — HarnessX 把 prompt、工具、记忆、控制流等运行时接口抽象为带类型的 harness 原语，通过“替换代数”组合装配，并由轨迹驱动的多智能体进化引擎 AEGIS 进行适配，把执行轨迹同时转化为 harness 更新和模型训练信号，从而闭合 harness–模型回路。在 ALFWorld、GAIA、WebShop、tau^3-Bench、SWE-bench Verified 五个基准上平均提升 14.5%，最高 44.0%，且基线越弱收益越大。结论是 Agent 的进步不一定靠模型 scaling，从执行反馈中组合与进化运行时接口是一条互补且可操作的路径。
- *(2026-10-05)* [EnvHarness：让静态环境随 Agent 一起进化](https://arxiv.org/abs/2608.19880) — 现有 Agent 训练环境由人工搭建且静态，对策略弱点“视而不见”，而环境生成方法又依赖领域专用流水线和高成本验证器。EnvHarness 提出一层可编程插件，在不修改底层逻辑的前提下包裹静态环境重塑其行为，并通过 EnvRigger 把目标策略当黑盒、观察其轨迹来合成针对性组件、再用新 rollout 验证。在四个领域五个基准上优于原始环境与领域专用生成流水线，held-out 实例最高提升 9.0 分且执行步数减少 9.8%，同时为强化学习提供更好的优化信号，实现策略与环境的定向共进化。
- *(2026-10-05)* [Darwin Gödel Machine：通过改写自身代码自我进化的编码 Agent](https://sakana.ai/dgm/) — Sakana AI 与 UBC Jeff Clune 实验室把 Schmidhuber 的 Gödel Machine 落地为可实证的方案：DGM 能读取并修改自己的 Python 代码库、用编码基准评估改动是否真的更好，并用开放式进化算法维护一个不断扩张的 Agent 档案库，让后续变异可以从任意“踏脚石”分支，避免过早收敛。实验中 SWE-bench 成绩从 20.0% 自动提升到 50.0%，Polyglot 从 14.2% 升到 30.7%，且这些改进可跨模型（Claude 3.5 Sonnet 优化后换用 o3-mini、Claude 3.7 Sonnet 仍更好）和跨语言（Python 上学会的改进迁移到 Rust/C++/Go）泛化，说明它发现的是通用 Agent 设计改进而非模型特化技巧。所有自修改均在沙箱、人工监督和受限网络下进行，档案库提供可追溯的改动谱系。
- *(2026-10-05)* [Raven：面向递归自我改进的“Harness 之 Harness”多智能体生态](https://github.com/EverMind-AI/Raven) — EverMind-AI 开源 Raven，定位为“harness of harnesses”，面向 RSI（递归自我改进）构建一个可信、持久、可自演化的多智能体生态系统，支持全领域协作。仓库包含 agents、evolver、bridge、benchmarks、插件与 TUI/Web 双前端等模块，已积累 1,763 次提交、约 5.2k star。
- *(2026-10-02)* [CodeAF：为开放模型打造的软件工厂式编码 harness](https://github.com/Agent-Field/CodeAF) — Agent-Field 开源了 CodeAF，一个用 Go 写成单二进制的编码 harness，目标是在开放模型上以更低成本获得前沿级编码能力，用单窗口替代多终端切换来管理多个 agent 任务。它在同一模型下的十款 harness 对比中位列 DeepSWE 第一，超过 Claude Code、Codex、OpenCode、Kilo 及 DeepSeek 自家 harness，且每个已解决问题成本最低。项目采用 Apache-2.0 许可，已有约 221 stars。
