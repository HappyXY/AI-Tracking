## LLM

- *(2026-10-02)* [Gemini 4 Argon 发布：1M 输出 token，先行开放给可信测试者](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/) — Google DeepMind 推出新一代前沿模型 Gemini 4 Argon，主打编码、企业知识工作与网络安全防御等复杂工作流，输出上限从 64K 提升到 1M token，上下文窗口同为 1M，支持文本、图像、视频、语音输入与文本输出。目前仅通过 Fairwind Program 向部分可信测试者开放，官方称开发者与企业/消费者的大范围开放将在收集反馈后推进，标准定价为每百万 token $4/$20，促销期 5 折至 $2/$10。
- *(2026-10-02)* [Artificial Analysis 实测：Gemini 4 Argon 智能指数 53，追平 GPT-6 Astra](https://x.com/ArtificialAnlys/status/2105392625788637299) — 在高推理档位下，Argon 的 AA Intelligence Index 得分为 53，与 GPT-6 Astra（max, 53）持平、高于 GPT-6.1 Sol（max, 52），比自家 Gemini 3.1 Pro Preview 高 23 分，让 Google 重回智能水平前三实验室。折扣价下每个任务成本 $1.99，约为 GPT-6 Astra 的 60%；AA-Omniscience 幻觉率仅 15%（GPT-6 Astra 为 51%），AutomationBench-AA 以 77.5% 排名第一，Terminal Bench 4 达 57%。新增 Long Decode Continuation 特性，可跨请求暂停并续写长回答，使推理输出最长可达 1M token 而不超时。
- *(2026-10-02)* [Quasar 438B：Multiverse Computing 发布欧洲最强推理模型](https://multiversecomputing.com/resources/introducing-quasar-438b-europe-s-leading-ai-model) — 这是一款 438B 级旗舰推理模型，面向企业级 agent 与编码场景，支持英语和西班牙语，在 Artificial Analysis Intelligence Index v4.1.1 上得分 43，为欧洲模型最高，领先 Mistral Medium 3.5（30）与参数量更大的 Nemotron 3 Ultra（38）。速度上 500 token 响应（含思考时间）仅需 15.3 秒，AA-LCR 长上下文推理得 75.0，Terminal-Bench v2.1 得 69.3，可通过 CompactifAI API 直接调用。
- *(2026-10-02)* [Context Language Models：让模型把上下文当作文件自己管理](https://arxiv.org/abs/2609.37725) — 论文提出 CLM，把上下文视为文件并允许模型不受限地更新，使其自主学习哪些信息值得保留，也天然适配多 agent 各自持有上下文文件的场景。零样本迁移到现有模型即超过当前 SOTA 上下文管理策略：BrowseComp-Plus 准确率高 11.4% 且 FLOPs 少 21.5%，12 小时 EdgeBench 高 5% 且 FLOPs 少 59%，24 小时多仓库 agent-swarm 任务同等算力下改进 65%。作者还用在线 RL 使 Qwen3.5-9B 在 BrowseComp-Plus 上提升 47.6% 且 FLOPs 少 12%，并配套 Suffix Cache Reuse 使服务端算力再降 35%。

## Agent

- *(2026-10-02)* [CodeAF：为开放模型打造的软件工厂式编码 harness](https://github.com/Agent-Field/CodeAF) — Agent-Field 开源了 CodeAF，一个用 Go 写成单二进制的编码 harness，目标是在开放模型上以更低成本获得前沿级编码能力，用单窗口替代多终端切换来管理多个 agent 任务。它在同一模型下的十款 harness 对比中位列 DeepSWE 第一，超过 Claude Code、Codex、OpenCode、Kilo 及 DeepSeek 自家 harness，且每个已解决问题成本最低。项目采用 Apache-2.0 许可，已有约 221 stars。

- *(2026-10-02)* [Phonon-2：900MB 以下最准的开源英文语音识别模型](https://huggingface.co/FermionResearch/Phonon-2) — FermionResearch 基于 NVIDIA parakeet-tdt-0.6b-v3 推出 Phonon-2，下载体积仅 164MB（约 2.1 bit 五级量化编码器），在 Open ASR Leaderboard 的七个英文测试集上平均 WER 5.21%，是该体积段最准的开源 ASR 模型，接近 2.5GB 全精度 teacher。速度上在 M5 MacBook Air 上约 20 秒转写 1 小时音频（174x 实时），8 核 Zen 5 上 143x，单张 H100 批量 128 时达 6680x。模型采用 CC-BY-4.0，CLI 与引擎代码为 Apache-2.0。
- *(2026-10-02)* [Origin：把 agent 运行时可观测性当作下一代端点安全](https://www.originhq.com/blog/sacr-maps-endpoint-observability) — 分析机构 SACR 的端点控制与防护报告将市场分为五个区域，把「agent 运行时可观测性」列为 Zone 3，Origin 正位于该区域。其做法是在端点上部署用户态传感器，完整记录 agent 的本地轨迹（prompt→工具调用→执行→系统响应），并对 prompt、工具与下游动作之间的正常关系建模，从而发现每个单步都看似合法、但整体意图异常的行为。文章认为 agent 攻击是非确定性的意图异常，签名和进程树都无法识别，只能靠可重放的 trace 来区分有用自动化与真实威胁。
- *(2026-10-02)* [从专有 LLM API 中窃取推理轨迹](https://arxiv.org/abs/2608.09867) — 论文发现主流厂商返回给客户端的加密思维链块在同一供应商生态内可跨会话、用户和模型通用，据此构造出可规模化的解密越狱：把强模型的加密推理块注入同厂商较弱的模型，即可让它逐字明文输出该推理过程，无需直接越狱强模型。该漏洞在 Anthropic、OpenAI、Google 上均得到验证，可绕过反蒸馏机制、大规模提取隐私数据（从公开仓库抓取的 315,320 个推理块中恢复出 367 条 PII 与 182 条凭据），并能泄露最终输出已安全拒绝的有害信息、实施不可见 prompt 注入。作者已负责任披露并提出密码学与系统层面的缓解方案。
- *(2026-10-02)* [open-edit：给编码 agent 用的开源视频编辑流水线](https://github.com/veedstudio/open-edit) — VEED 开源了 agent 驱动的视频编辑流水线 OpenEdit，没有 GUI 也没有时间线，用户只需对 Claude Code、Codex 或 Gemini CLI 描述需求，它就完成转写、动效设计、渲染并输出 MP4，成品与其生成代码一起保存在项目的 runs/ 目录。安装只需 `npx skills add veedstudio/open-edit`，首次运行会自动检查 Node 与 ffmpeg、注册会话钩子，并让用户选择 VEED 托管转写、本地 WhisperX（离线、首个模型约 2GB）或自带服务。项目采用 Apache-2.0，已有约 1.4k stars。
